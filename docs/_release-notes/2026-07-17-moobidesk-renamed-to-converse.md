The product previously known as **Moobidesk** is now called **Converse** throughout the developer documentation. All functionality is identical — only the product name has changed, so there is no API or behavioural change to act on.

Converse is a unified conversational platform for omnichannel customer engagement across WhatsApp, Email, and Facebook Messenger, with conversation management, queue routing, broadcast messaging, and real-time analytics.

The login URL is unchanged — you still access Converse through your organization's `moobidesk.com` URL with your existing credentials.
