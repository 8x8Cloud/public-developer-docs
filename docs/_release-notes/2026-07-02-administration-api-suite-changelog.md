The Administration API Suite now has a dedicated **changelog** so you can track every change to the suite in one place, newest first. Whenever an API in the suite gains a new capability, changes behaviour, or has its documentation clarified, the change is recorded there.

The changelog covers all of the APIs in the suite — User Management, Ring Group Management, Phone Number Management, Site Management, and Contact Management — and you can filter by API for a focused view. Each entry is tagged with a change type (for example, non-breaking additions versus breaking changes) and the API version it applies to.

Change types follow the suite's [API Change Policy](/administration/docs/api-change-policy), which defines what counts as a breaking versus a non-breaking change and how each is versioned and communicated.
